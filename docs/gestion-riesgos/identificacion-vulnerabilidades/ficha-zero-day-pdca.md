## Reglas

- Traten el CVE como recién publicado y sin parche disponible.
- Ignoren soluciones, parches y mitigaciones históricas.
- Consulten CVE.org, NVD y el aviso oficial del proveedor.
- No busquen instrucciones ni herramientas para atacar sistemas.
- No realicen cambios en equipos o redes reales.

## Glosario breve

| Término | Significado para este ejercicio |
|---------|---------------------------------|
| **Vector CVSS** | Cadena que comienza con `CVSS:` y resume cómo se obtuvo el puntaje. Cópiela; no tienen que calcularla. |
| **Control temporal** | Medida defensiva usada mientras no existe un parche. |
| **Registro o log** | Historial de eventos producido por un sistema o aplicación. |
| **Riesgo residual** | Riesgo que permanece después de aplicar los controles. |
| **Hardening** | Configuración segura que reduce funciones, servicios y accesos innecesarios. |

## B. Responder mediante PDCA

| Fase | Respuesta breve del grupo |
|------|---------------------------|
| **Planear** — activo y misión expuestos; objetivo y responsable | |
| **Hacer** — una acción para reducir la exposición y una para mantener la continuidad | |
| **Verificar** — comprobación del uso autorizado y de la restricción; registro o alerta por revisar | |
