<decisions_made>

- Plataforma objetivo: VM Ubuntu 24.04 separada; no WSL2 y no “iptables en
  Windows”. Windows u otro host será únicamente el segundo extremo de prueba.
- Topología prevista: NAT para actualizaciones más Host-only para pruebas
  deterministas entre máquinas. Las direcciones se detectarán; no se fijará un
  `/24` sin derivarlo de la interfaz.
- Planificar todo el recorrido antes de corregir archivos para preservar la
  secuencia didáctica entre las partes 1 y 2.
- La preparación de instalación fresca será un solo paso acotado. En Ubuntu 24.04
  se debe inspeccionar la configuración deb822 habitual
  `/etc/apt/sources.list.d/ubuntu.sources`; no sobrescribir ciegamente el legado
  `/etc/apt/sources.list` ni añadir repositorios de terceros.
- La práctica principal será IPv4 explícita y sus pruebas deberán forzar IPv4;
  deberá aclararse que `iptables` no constituye cobertura IPv6.
- Debe usarse un listener real y un segundo equipo para probar INPUT; `curl` hacia
  Internet sólo valida OUTPUT y tráfico de retorno.
- La persistencia deberá sobrevivir a un reinicio real o denominarse con precisión
  “backup/restauración manual”.
- Cada práctica debe capturar el ruleset inicial, modificarlo con un orden seguro y
  restaurarlo al finalizar.

## Critical Anti-Patterns (do NOT repeat these)

- Añadir un DROP después de `ESTABLISHED,RELATED` y afirmar que bloquea la
  respuesta: diseñar la prueba de modo que el orden y los contadores demuestren el
  resultado.
- Declarar una regla INPUT “probada” sin servicio escuchando ni cliente externo:
  levantar listener, verificarlo con `ss` y conectar desde el segundo equipo.
- Ejecutar `iptables -F` sin snapshot/restauración o antes de asegurar políticas
  integradas seguras.
- Registrar tráfico sin `--limit`, usar una subred `/24` inventada o confundir
  IPv4 con cobertura total.
- Presentar una sola regla MASQUERADE como router completo: NAT requiere también
  forwarding, dos interfaces/segmentos y reglas FORWARD.
- Mezclar el backend `iptables-nft` con comandos `nft`/legacy sin explicar el
  estado real de Ubuntu 24.04.
